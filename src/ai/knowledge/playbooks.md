# Как исправлять: рабочие приёмы по семействам правил

## Производительность
**Медленный LCP** — обычно: главный контент — большое изображение без оптимизации; блокирующий CSS в head; медленный TTFB.
Приёмы: отдать hero-картинку в AVIF/WebP с правильным `srcset`; добавить `<link rel="preload">` для главного изображения; вынести критический CSS инлайном, остальное — с `media="print" onload`; включить HTTP/2 или HTTP/3; кэширование на CDN и у провайдера; сжатие brotli/gzip.
**CLS** — приёмы: задавать `width`/`height` или `aspect-ratio` для изображений, видео и iframe; резервировать место под баннеры и рекламу; не вставлять контент над существующим без отступа; использовать `font-display: swap` с подстроенными метриками (или `optional`).
**TBT и Long Tasks** — приёмы: разбивать тяжёлые задачи на чанки через `requestIdleCallback`/тайм-слайсы; выносить тяжёлые вычисления в Web Worker; code-splitting и tree-shaking; отложить загрузку сторонних скриптов (аналитика, чаты, виджеты) до взаимодействия или через `requestIdleCallback`; не рендерить большие списки целиком — виртуализация.
**Много ресурсов** — приёмы: объединять мелкие файлы (CSS/JS в бандл), шрифты — подмножество и `preload`, картинки — в AVIF/WebP, ленивая загрузка (`loading="lazy"`) для нижних секций, инлайн маленьких SVG, кэш с фингерпринтом.
**Высокий TTFB** — приёмы: кэш на CDN, кэш страниц на сервере, оптимизация запросов к БД, индексы, устранение N+1, соединение с бэкендом ближе к пользователю.

## SEO
**Нет title** — приёмы: добавить уникальный `<title>` 50–60 символов с ключевым запросом в начале; на многостраничных сайтах — шаблонизация вида «Услуга — Компания».
**Нет description** — приёмы: добавить `<meta name="description">` 120–155 символов, уникальный на страницу; не дублировать на всех страницах.
**Нет canonical** — приёмы: `<link rel="canonical" href="...">` с абсолютным URL; на пагинации и параметрах — канонизировать на основную версию.
**Нет Open Graph** — приёмы: og:title, og:description, og:image (1200×630), og:url, og:type;og:image — абсолютный URL.
**Нет H1 / несколько H1** — приёмы: один H1 с ключевым запросом; H2–H3 как подзаголовки, без пропусков уровней.
**alt отсутствует** — приёмы: alt = что на картинке и зачем она; для декоративных — `alt=""`; не писать «картинка1».
**Битые внутренние ссылки** — приёмы: найти источник (шаблон, CMS, старая ссылка), исправить или снять с публикации; настроить 301 на релевантную страницу; проверить карту сайта.
**Нет robots.txt** — приёмы: создать `/robots.txt` с правилами и ссылкой на sitemap.xml.

## Безопасность
**Нет CSP** — приёмы: собрать политику в режиме отчёта (`Content-Security-Policy-Report-Only`), посмотреть violations, затем перейти в enforce; начинать со `default-src 'self'`, постепенно добавляя домены; для скриптов — nonce или hash вместо `unsafe-inline`.
**Нет HSTS** — приёмы: отправлять только по HTTPS, затем `Strict-Transport-Security: max-age=31536000; includeSubDomains`; начинать с короткого max-age и наращивать.
**Нет X-Content-Type-Options** — приёмы: добавить `nosniff`; риск минимален, правка безопасна.
**Нет X-Frame-Options** — приёмы: `DENY`, если встраивание не нужно, иначе `SAMEORIGIN`; либо `frame-ancestors` в CSP.
**Нет Referrer-Policy** — приёмы: `strict-origin-when-cross-origin` (по умолчанию для большинства).
**Mixed content** — приёмы: перевести ресурсы на HTTPS, убрать http-ссылки, добавить `Content-Security-Policy: upgrade-insecure-requests` как временную меру.

## Доступность (axe-core)
**image-alt** — приёмы: осмысленный alt; декоративные изображения — `alt=""`; для сложных схем — `aria-label` или подпись.
**color-contrast** — приёмы: поднять контраст до 4.5:1 (3:1 для крупного текста и границ элементов); не полагаться на цвет как единственный носитель смысла.
**html-has-lang** / **document-has-title** — приёмы: `<html lang="ru">` и `<title>`.
**button-name / link-name** — приёмы: видимый текст кнопки; иначе `aria-label`; ссылки «нажмите здесь» — переписать осмысленно.
**landmark-one-main / region** — приёмы: обернуть контент в `<main>`, навигацию в `<nav>`, шапку в `<header>`.
**page-has-heading-one** — приёмы: добавить H1.
**nested-interactive** — приёмы: не вкладывать ссылку в кнопку и наоборот.
**select-name / label** — приёмы: `<label for="id">` или `aria-label`.
**focus visible** — приёмы: не убирать `outline` без замены на заметный `:focus-visible`.
**form field multiple labels** — приёмы: один label на поле.

## Контент
**Пустые ссылки** (`href="#"`, `href=""`) — приёмы: убрать или дать осмысленный href; для кнопок-действий — `<button>`.
**Дублирующиеся заголовки** — приёмы: уникализировать H2–H3 в повторяющихся блоках (карточки, списки услуг).
**Слишком короткий/длинный title** — приёмы: 50–60 символов, ключевая фраза в начале.
**Нет структурированных данных** — приёмы: JSON-LD Schema.org (Article/Product/Organization/LocalBusiness) с фактическими данными сайта; проверять валидатором.
**Мало текста** — приёмы: для коммерческих страниц — 300–800 слов по теме, ответы на частые вопросы, блок FAQ.
