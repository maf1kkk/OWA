# Пороги и нормативы

## Core Web Vitals (пороги Google)
- **LCP** (Largest Contentful Paint): ≤ 2500 мс — хорошо; 2500–4000 мс — требует улучшения; > 4000 мс — плохо.
- **INP** (Interaction to Next Paint): ≤ 200 мс — хорошо; 200–500 мс — требует улучшения; > 500 мс — плохо.
- **CLS** (Cumulative Layout Shift): ≤ 0.1 — хорошо; 0.1–0.25 — требует улучшения; > 0.25 — плохо.
- **TTFB**: ≤ 800 мс — хорошо; 800–1800 мс — требует улучшения; > 1800 мс — плохо.
- **FCP**: ≤ 1800 мс — хорошо; 1800–3000 мс — требует улучшения; > 3000 мс — плохо.
- **TBT** (Total Blocking Time, лабораторная метрика вместо INP): ≤ 200 мс — хорошо; 200–600 мс — требует улучшения; > 600 мс — плохо.

## Другие ориентиры производительности
- Полная загрузка (load): ≤ 2000 мс — хорошо; 2000–5000 мс — требует улучшения; > 5000 мс — плохо.
- DOMContentLoaded: ≤ 1000 мс — хорошо; 1000–3000 мс — требует улучшения; > 3000 мс — плохо.
- Long Tasks: 0–1 — хорошо; 2–5 — терпимо; > 5 — плохо (блокирует главный поток).
- Количество ресурсов: ≤ 50 — хорошо; 51–150 — терпимо; > 150 — много запросов.
- Ресурс: > 200 КБ — стоит сжать; > 500 КБ — критично для мобильного интернета.

## SEO-ориентиры
- Title: 50–60 символов (до 70). Ключевое слово ближе к началу.
- Description: 120–155 символов. Уникальный, с призывом к действию.
- Ровно один H1 на страницу, H1 содержит ключевую фразу.
- Canonical на каждой странице; на страницах с параметрами — на основную версию.
- Open Graph: og:title, og:description, og:image, og:url, og:type.
- Alt: описывает изображение, пустой alt="" — только для декоративных.
- robots.txt: доступен на /robots.txt, задаёт правила для поисковиков.
- Внутренние ссылки: не битые, не более 3–4 «прыжков» до целевой страницы.
- Структурированные данные (JSON-LD): рекомендуются для статей, товаров, организаций, событий.

## Заголовки безопасности (что должно быть)
- **Content-Security-Policy** — ограничивает источники скриптов, стилей, фреймов, картинок. Отсутствие CSP — самая частая и самая недооценённая находка.
- **Strict-Transport-Security** — только для HTTPS: `max-age=31536000; includeSubDomains`.
- **X-Content-Type-Options: nosniff** — запрещает браузеру угадывать тип содержимого.
- **X-Frame-Options** — DENY или SAMEORIGIN (защита от кликджекинга); альтернатива — `frame-ancestors` в CSP.
- **Referrer-Policy** — `strict-origin-when-cross-origin` или `no-referrer`.
- **Permissions-Policy** — ограничение доступа к камере, микрофону, геолокации.

Смешанное содержимое (mixed content): на HTTPS-сайте любые http-ресурсы блокируются браузером — это поломка функциональности, а не только предупреждение.

## Доступность: WCAG 2.1 и ГОСТ
Российский стандарт **ГОСТ Р 52872-2019** «Интернет-ресурсы и другая информация, представленная в электронно-цифровой форме… Требования доступности для людей с инвалидностью и других лиц с ограничениями жизнедеятельности» построен на WCAG 2.1. В отчёте можно ссылаться на него как на нормативную базу доступности.

Ключевые критерии успеха (WCAG 2.1) и что они означают на практике:
- **1.1.1 Нетекстовые элементы** — у изображений есть текстовая альтернатива.
- **1.3.1 Информация и связи** — структура выражена разметкой (заголовки, списки, таблицы), а не только визуально.
- **1.4.3 Контраст** — текст контрастен с фоном (минимум 4.5:1 для обычного текста, 3:1 для крупного).
- **1.4.11 Контраст нетекстовых элементов** — элементы интерфейса и границы полей различимы (3:1).
- **2.1.1 Клавиатура** — всё доступно с клавиатуры; нет «ловушек фокуса».
- **2.4.1 Обход блоков** — есть способ пропустить повторяющиеся блоки.
- **2.4.7 Видимый фокус** — фокус виден.
- **3.1.1 Язык страницы** — задан `lang`.
- **3.3.2 Метки или инструкции** — поля формы подписаны.
- **4.1.2 Имя, роль, значение** — элементы с доступным именем и корректной ролью.

Уровни соответствия WCAG: A (минимальный), AA (рекомендуемый), AAA (максимальный). Для коммерческого отчёта ориентир — AA.

## Оценка и приоритеты разделов
Для интегральной оценки по 100 баллов разделы взвешиваются так: производительность 0.30, SEO 0.25, безопасность 0.20, доступность 0.15, контент 0.10. Оценка 85+ — хорошо, 60–84 — есть что улучшить, ниже 60 — серьёзные проблемы.
